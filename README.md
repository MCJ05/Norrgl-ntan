# Norrgl-ntan
En responsiv startsida för naturdestinationen Norrgläntan.

## Om webbplatsen
En startsida där man hittar information om:
* Naturen väntar i Norrgläntan
* Nära till naturen
* Upplev Norrgläntan
  - Vandra
  - Paddla
  - Upptäck 
* Planera ditt besök

## Tekniker
* HTML
* CSS
* CSS Grid
